# Sample Idea Input

## Working title

Course Project Scope Coach

## Rough idea

An agent that helps students turn a vague course-project idea into a realistic plan before they start coding.

## Target user

University students working alone or in small teams.

## Desired outcome

A portfolio-ready MVP that can be demonstrated in an interview.

## Constraints

- Four weeks
- One developer
- Limited API budget
- Must run locally except for model and search calls

## Questions for the agent

1. What similar tools or projects already exist?
2. What is a credible differentiator?
3. What can be completed in four weeks?
4. What are the functional list, person-day range, monetary cost, and architecture?
